What it does

One board for the whole team

Admins assign the work. Employees run the job from their phone. Everything in between is logged automatically.

AUTH · RBAC
Role-based access
JWT auth with access/refresh rotation across Admin, Manager, and Employee roles — enforced at the query level.
TASKS
Lifecycle management
A validated status machine from Pending to Completed, with a full timestamped audit trail on every change.
GPS
Verified attendance
Check-in and check-out capture real GPS coordinates, with working hours calculated automatically.
MAPS
Live team map
Customer sites and active employees rendered on an interactive map — built on OpenStreetMap, zero API cost.
PHOTOS
Proof of work
Before/after job photos upload straight to Cloudinary from the field, attached to the task record.
ALERTS
In-app notifications
Assignment and completion events push a notification the moment they happen, with unread tracking.
METRICS
Live analytics
Completion rate, task mix, and workload — pulled straight from the database into charts on the dashboard.
AUDIT
Action logging
Sensitive actions — hires, cancellations — are recorded with who, what, and when, for accountability.
How a job moves

The task lifecycle

Every job passes through the same guarded states — the backend rejects any transition that skips a step.

ASSIGNED
Manager routes the job to an employee.
ACCEPTED
Employee confirms they're taking it on.
IN PROGRESS
Work starts — timer begins for duration tracking.
ON HOLD
Paused if blocked — resumes back to In Progress.
COMPLETED
Closed out, duration logged, manager notified.
